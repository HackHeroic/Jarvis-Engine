3. New UI Components

Memory Panel

Collapsible sidebar showing what Jarvis knows: facts, preferences, patterns, constraints. Grouped by type with confidence indicators.

PEARL Insight Banner

Animated banner in chat: "I noticed you skip morning tasks — I've adjusted your schedule." Appears after pattern detection.

Document Classification Toast

After PDF upload: "Practice problems detected — 10 problems linked to 3 tasks." Slides in from bottom-right.

4. Mode Toggle (Demo / Live)

Demo Mode: Uses mock data from demoData.ts with simulated streaming. Prompt selectors auto-trigger pre-built responses. Works offline — no LM Studio needed.

Live Mode: Hits the real backend. Prompt selectors fill the input but user clicks Send. Real streaming, real schedule, real memory extraction.

Both modes show the same prompt selector cards. Both modes show memory panel + PEARL insights. The difference is data source (mock vs real).

Demo Flow for VC Pitch

1. Open app → Light mode, clean hero with Spline 3D brain, "Reclaim your focus" headline

2. Click "Try Chat" → See 4 scenario cards

3. Click "Learn a Concept" → Jarvis explains Dijkstra's with structured response (shows general QA works)

4. Click "Plan Complex Task" → Tasks decomposed → animated schedule → draft review UX

5. Click "Add Contradicting Habit" → Schedule recalibrates → animation shows tasks shifting

6. Click "Upload Material" → Document classification toast → "problems linked" feedback

7. Show Memory Panel → "Jarvis knows" sidebar slides in → facts, patterns listed

8. PEARL Insight → Banner: "I noticed you skip morning tasks" → Schedule already avoids mornings
