Three Approaches for the Demo Update

Each delivers the 3-act demo story. They differ in scope and risk.

A

Recommended: Polish + Strategic Additions

~8-10 hours | Low risk | High impact

Visual Polish
  • Light mode as default
  • Clean up color inconsistencies
  • Update intent badge names (PLAN_DAY not GREETING)
  • Professional typography + spacing
Memory Visibility (NEW)
  • Small "Jarvis knows" panel in sidebar
  • PEARL insight banners in chat
  • Memory indicator badge on responses
Draft UX Cleanup
  • Wire accept/reject to new Supabase DraftStore
  • Add rejection reason prompt
  • Visual draft badge styling
Document Feedback
  • Show classification result after upload
  • "Practice problems detected" toast/banner
  • Topics linked indicator
Why recommended: Delivers all 3 demo acts. Low risk because it builds on existing components. Light mode default + memory panel = instant "wow" factor.
B

Minimal: Visual Polish Only

~4-5 hours | Lowest risk | Medium impact

  • Light mode default
  • Updated intent badges and colors
  • Clean typography and spacing
  • Fix any broken UI elements
  • Architecture diagrams page updated
Trade-off: Safe, but the demo won't show memory/PEARL — the moat stays invisible. Acts 2 and 3 of the demo are just "it works" without the differentiating UX.
C

Full Rebuild: New Design System

~16-20 hours | High risk | Highest potential

  • Completely new visual design (shadcn/ui or custom)
  • Memory panel as a first-class sidebar
  • Full draft negotiation with inline editing
  • Document intelligence results page
  • PEARL insights timeline
  • New home page with product narrative
Trade-off: Too much for 2 days. Risk of breaking existing functionality. Save for post-pitch v2.

The 3-Act Demo Script (with Approach A)

Act 1: Core Loop (60s)

Brain dump "I have a DL contest Friday" → tasks decomposed → schedule appears → edit a task duration → accept. Shows: deterministic scheduling, anti-guilt pacing.

Act 2: Depth (60s)

Add habit "I study best after lunch" → schedule shifts → upload practice PDF → "10 problems linked to your tasks" banner. Shows: document intelligence, constraint adaptation.

Act 3: The Moat (60s)

"Jarvis knows" sidebar shows learned facts. PEARL insight banner: "I noticed you skip morning tasks." Schedule already avoids mornings. Shows: memory → constraint bridge.
